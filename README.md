# Persecution-belief sycophancy in LLMs

Prompts, grading rubrics, raw results, and figures for the blog post:

**[Unsubstantiated beliefs of persecution can elicit sycophancy from LLMs](https://peter-fields.github.io/sycophancy-persecution-beliefs/)**

The post contains the full methodology and discussion.

This project was done as part of the BlueDot Technical AI Safety Project Sprint.

The prompts and rubrics were written with the help of Claude Opus 4.8 and Opus 5.

```
prompts/   the conversations given to the models under test
rubrics/   the grader rubrics
results/   model responses, judge grades, and warrant labels
figures/   plots used in the post
```
